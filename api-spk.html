בין API ל-SDK?

שתי מילים ששומעים כל הזמן בעולם הפיתוח. בשיעור הזה נבין את ההבדל ביניהן דרך דוגמה ממסעדה, ודרך מסך התחברות אמיתי. גללו לאט — אפשר לעצור בכל רגע באמצע ולהסביר.

ארגז הכלים למפתח

אז מה זה SDK?

בואו נחזור לדוגמת ההתחברות לבנק — הפעם מנקודת המבט של מי שבונה את האתר, וצריך לכתוב בעצמו כל שלב בדרך.

1להכין "מעטפה" מסודרת שהשרת יידע לקרוא
2לצרף פרטים שמזהים מי שולח ומה מבקשים
3לשלוח את הבקשה עם שם המשתמש והסיסמה
4לחכות לתשובה, ולדעת מה לעשות אם היא לא מגיעה
5לקרוא את התשובה ולהבין אם ההתחברות הצליחה
client.login("itamar123", "pass123")

שורה אחת קצרה. ה־SDK עושה בשבילכם את כל 5 השלבים האלה מאחורי הקלעים.

לסיכום

API מול SDK, זה לצד זה

API

דרך מוגדרת לתקשר עם מערכת קיימת. בדיוק כמו התפריט שדרכו מזמינים מהמטבח — הוא קובע אילו בקשות אפשר לשלוח ואיזו תשובה תקבלו בחזרה.

SDK

ארגז כלים שלם שעוזר לבנות תוכנה שמשתמשת במערכת הזאת — כולל בתוכו שימוש ב־API, ועוד הסברים, קיצורי דרך וכלי עזר שחוסכים לכם המון עבודה.

SDK
שימוש ב־API
הסברים קיצורי דרך עזרה כשמשהו משתבש

תודה!
